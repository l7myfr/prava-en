## What's new

- **Back gesture in tests.** The first back closes an open picture, rules sheet or signs dialog. The next one saves the test and returns you to where you started it. Going back no longer resets the answers you've given.
- **Answers stay hidden until the end.** New tests and the quick exam show right/wrong only once every question is answered. Turn on "Show result immediately" in test setup or in the test header if you want it straight away.
- **Update check.** Home shows a card with a Download button when a newer version is out.

## Installing

Install `Prava-EN.apk` over the app you have. Your progress stays. This is the last version you need to install by hand.
