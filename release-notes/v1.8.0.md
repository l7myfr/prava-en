## What's new

- **Updates install from inside the app.** When a new version is out, a pop-up asks if you want to update. Tap **Update** and it downloads in the background, with a progress bar on Home, and no browser opens. When it's done, Android's installer opens by itself. Tap **Later** and Home shows a small update card instead; the pop-up comes back the next time you open the app.
- **First time only:** Android asks you to allow Prava EN to install apps. Allow it, come back, and tap **Install** on Home.

## Installing

Install `Prava-EN.apk` over the app you have. Your progress stays. This is the last version that updates through the browser; from here on, updates install from inside the app.
